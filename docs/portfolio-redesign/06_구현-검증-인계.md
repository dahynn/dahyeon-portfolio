### 2026-09-12 로컬 화면 캡처 추가

- 세 프로젝트의 기술 사례 앞에 `서비스 한눈에 보기`를 추가했습니다. 대상 사용자, 해결하려는 문제, `사용자 행동 → 처리/판단 → 사용자 결과` 순서를 먼저 읽고 기술 사례로 넘어갑니다.
- CapSure는 반응형 **모바일 웹**을 390×844 뷰포트에서 실제 실행해 상품 선택, 가상 결제 전 확인, 증권 확인 장면을 캡처했습니다. 포트폴리오에는 기기 프레임과 한 문장 주석만 추가했으며 화면 내용은 편집·합성하지 않았습니다.
- 캡처 데이터는 저장소의 `demo@example.com` 로컬 seed와 Fake PG입니다. 실제 보험 계약·카드 승인·송금은 발생하지 않았습니다.
- Roundy는 촬영 동의와 테스트 계정이 없는 상태여서 이용 흐름 도식만 두고 실제 화면인 것처럼 표현하지 않았습니다.
- SAN은 로컬 서버를 분리 환경에서 구동했지만, 인증 경로가 현재 보안 설정에서 401을 반환해 실제 검색 캡처를 추가하지 않았습니다. 외부 GitHub 로그인·AI 호출은 시도하지 않았습니다.
- CapSure 원본 화면은 UUID 전체가 작은 모바일 카드 폭을 넘어가던 문제를 수정했습니다. 새 발급 번호는 `CS-YYYYMMDD-XXXXXXXX` 형태이며, 고객 화면에는 앞·뒤 식별자만 표시합니다. 원본 값은 계약 조회를 위해 서버에 유지됩니다.
- CapSure는 `구독형 보험 프로세스 시뮬레이터`로 명시하고, 월 단위 보장 구성·납입·청구·계약 유지가 이어져야 하는 문제를 앞단에 복원했습니다.
- 구름톤 유니브 4기의 여정 설명은 `개발자 커뮤니케이션`만 남겼습니다. 프로필 강점은 외부 링크·영문 역량명 대신 다현의 해석 문장 3개로 교체했고, 소개 제목 크기도 줄였습니다.
- 세 프로젝트의 기술 사례 문장도 `문제 상황 → 제가 판단한 기준 → 제가 구현한 방식 → 확인한 결과` 순서의 1인칭 회고 말투로 통일했습니다.
